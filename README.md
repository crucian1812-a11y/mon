# Семейный бюджет — учёт расходов для двух телефонов

Android-приложение для учёта расходов семьи в рублях. Данные хранятся на телефоне
и синхронизируются через JSON-файл в вашем репозитории GitHub, поэтому оба телефона
видят одни и те же расходы.

## Что умеет

- Добавление расходов: сумма в ₽ (можно складывать, например `350+120,50`), категория, дата, комментарий.
- 17 базовых категорий: Продукты, Кафе и рестораны, Транспорт, Автомобиль, ЖКХ, Связь и интернет,
  Здоровье и аптека, Одежда и обувь, Дети, Дом и быт, Развлечения, Подарки, Красота и уход,
  Образование, Питомцы, Путешествия, Прочее.
- Свои категории: добавление (название + значок-эмодзи), переименование и удаление прямо в приложении.
  Добавить категорию можно и при вводе расхода (кнопка «Новая»).
- Итог за месяц и разбивка по категориям с процентами; нажмите на категорию, чтобы увидеть только её расходы.
- Переключение месяцев, список расходов по дням, рядом с расходом видно, кто его внёс («Мама», «Папа»).
- Работает без интернета: изменения сохраняются на телефоне и отправляются в GitHub, как только появится связь.
- Если оба телефона внесли расходы одновременно, данные объединяются без потерь.

## Установка

1. Откройте на телефоне страницу **Releases** этого репозитория и скачайте `FamilyBudget.apk`
   из последней сборки (APK собирается автоматически GitHub Actions при каждом изменении кода).
2. Установите APK (Android попросит разрешить установку из браузера/файлового менеджера).
3. Повторите на втором телефоне.

## Настройка синхронизации (один раз)

1. На github.com создайте **приватный** репозиторий для данных, например `family-budget-data`.
2. Создайте токен: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
   - *Repository access*: **Only select repositories** → выберите репозиторий с данными;
   - *Permissions → Repository permissions → Contents*: **Read and write**;
   - *Expiration*: максимальный срок (когда истечёт — создайте новый и вставьте в приложение).
3. В приложении откройте ⚙️ **Настройки** на **обоих** телефонах и введите одинаковые:
   владельца (ваш логин GitHub), название репозитория и токен. Поле «Чей это телефон» — у каждого своё.
4. Нажмите **«Сохранить и синхронизировать»**.

Данные лежат в файле `family-budget/data.json` в репозитории; каждое изменение — отдельный коммит,
поэтому в GitHub видна вся история и при необходимости можно откатиться.

## Как устроена синхронизация

- Каждый расход и категория имеют уникальный id и время последнего изменения.
- Удалённые записи не стираются, а помечаются `deleted: true` — чтобы удаление «доехало» до второго телефона.
- При синхронизации приложение скачивает файл из GitHub, объединяет его с локальными данными
  (для каждой записи побеждает более свежая правка) и загружает результат. Если второй телефон успел
  записать файл в этот момент, GitHub отклонит запись, и приложение повторит попытку с новыми данными.
- Синхронизация запускается при открытии приложения, через 2 секунды после любого изменения и по кнопке ⟳.

## Сборка из исходников

Нужны JDK 17+ и Android SDK (compileSdk 36):

```bash
./gradlew testDebugUnitTest   # тесты
./gradlew assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
```

APK подписывается ключом `app/family.keystore` из репозитория — так все сборки (локальные и из GitHub Actions)
имеют одну подпись и устанавливаются поверх друг друга. Это семейный ключ, он не подходит для публикации в Google Play.

Стек: Kotlin, Jetpack Compose (Material 3), kotlinx.serialization, GitHub Contents API.
